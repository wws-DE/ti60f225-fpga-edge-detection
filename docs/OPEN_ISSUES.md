# 未解决问题（2026-10-22）

以 [完整交接第 4–5 节](HANDOFF_2026-10-22.md) 为准。

1. 普通光照弱木纹、细线和轮廓仍有漏检，部分需要补强光；灰度/中值可见的边也可能在 Sobel 中消失。
2. 断点、短碎边、杂点仍存在，细化不能损伤分叉、短线和相邻双线。
3. 靠近目标时，用户确认彩色/灰度清楚但中值细节消失；保边中值 A 尝试改善，尚无实机验收结果。
4. 最新 A 在四组相关噪声合成案例增加杂边；用户接受少量增噪以恢复弱细节，不能改称原质量门槛全通过。
5. 最新 bit 的真实精度、采集 FPS、长期稳定性及 Flash 固化未完成专项实测。
6. 正式 PostgreSQL / schema 和旧控制状态未同步；当前以已授权本地报告和追加审计追踪，不自动迁移或改写正式状态。

历史失败保留：960×540 半屏显示、部分早期链路 DDR 异常、旧细化分叉损失、降阈值/平滑预检失败。历史组件库中的 Canny/拟合等并不等于当前实时链已接入。

恢复时第一步是验收保边中值 A 对比细化 v1.1；之后单独设计弱边判定，再考虑受约束连通和细化。每项完成后停待用户验收。
